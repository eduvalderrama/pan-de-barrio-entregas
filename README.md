# Pan de Barrio Entregas

Landing de conversión para **The Accelerator** (caso ficticio: delivery de pan artesanal en Lima).

## Stack

- [Astro](https://astro.build)
- Tailwind CSS 4
- TypeScript (config y datos)

## Desarrollo

```bash
pnpm install
pnpm dev
```

Abre `http://localhost:4321`.

## Build

```bash
pnpm build
pnpm preview
```

## Assets

Imágenes en `public/` (`/hero-bread.svg`, `/logo.svg`) — rutas absolutas para que carguen en dev y producción.

## WhatsApp

Edita `src/config/site.ts` → `whatsappNumber`.

## Entrega Accelerator

- Deploy (Vercel recomendado, root del proyecto)
- Capturas por sección + enlace publicado
